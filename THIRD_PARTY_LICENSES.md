# Third-party licences

Orikata's fold-angle solver (`src/animation/solver/`) is a CPU TypeScript port of the constraint-based thin-shell solver in Amanda Ghassaei's Origami Simulator (https://github.com/amandaghassaei/OrigamiSimulator), described in "Fast, Interactive Origami Simulation using GPU Computation" (Ghassaei, Demaine, Gershenfeld, 7OSME 2018). The mechanical model is reproduced; the GPU implementation is not.

The `fold` npm package (https://github.com/edemaine/fold) is used for FOLD-format utilities where it helps.
